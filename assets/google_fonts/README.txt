Сюда можно положить файлы шрифтов (.ttf) — тогда приложение не будет качать их из интернета
и шрифты появятся сразу, даже без сети:

Unbounded-Medium.ttf, Unbounded-Bold.ttf, Unbounded-ExtraBold.ttf
Manrope-Regular.ttf, Manrope-Medium.ttf, Manrope-Bold.ttf, Manrope-ExtraBold.ttf
Nunito-SemiBold.ttf, Nunito-Bold.ttf, Nunito-ExtraBold.ttf, Nunito-Black.ttf

Скачать: fonts.google.com -> Unbounded / Manrope / Nunito -> Download family -> папка static.
Если файлов нет, приложение само скачает шрифты при первом запуске (нужен интернет).
